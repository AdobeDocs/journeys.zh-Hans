此mixin用在历程模式中（与journeyStepEvent相关）。 它包含以下字段：

## journeyID

主历程的ID。

类型：字符串

## journeyVersionID

历程版本的ID。 此id表示历程的身份。

类型：字符串

## name

历程的名称。

类型：字符串

## 描述

历程的描述。

类型：字符串

## version

版本，表示为`major`.`minor`

类型：字符串

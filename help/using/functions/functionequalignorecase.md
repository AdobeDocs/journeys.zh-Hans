# equalIgnoreCase {#equalIgnoreCase}

将第一个参数字符串与第二个参数字符串进行比较，忽略大小写注意事项。

## 类别

字符串

## 函数语法

`equalIgnoreCase(<parameters>)`

## 参数

* 字符串

## 签名和返回的类型

`equalIgnoreCase(<string>,<string>)`

返回布尔值。

## 示例

`equalIgnoreCase("rowing is great", "rowing is GREAT")`

返回真。
